# Importar catálogo de Grok

1. Pide a Grok (app) el catálogo del perfil con el mensaje de siempre.
2. Aquí, en esta carpeta: **Add file → Create new file**.
3. Nombre: `catalogo.json`. Pega dentro la respuesta de Grok tal cual.
4. **Commit changes**.

En un minuto la web se actualiza con todos los productos y sus fotos.
El archivo se borra solo después de importarlo.
